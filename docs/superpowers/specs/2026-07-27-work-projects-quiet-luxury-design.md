# Work APP 项目管理简约轻奢改版

## 目标

仅重新设计 Work APP 的项目管理页面 UI，保留现有五份合同生成、刷新、签署、锁定、倒计时联动、错误与加载逻辑。视觉以用户选定的方案 1 白色修订版为准。

## 视觉方向

- 页面和合同区域使用纯白 `#ffffff`，不保留淡黄、米白、纸张纹理或灰色桌面底。
- 以石墨黑为主文字和主操作色，香槟金 `#9a6a24` 只用于金额、序号和少量操作细节。
- 页面采用连续的单列合同台账，不使用卡片套卡片、厚边框、拟物纸张或重阴影。
- 标题和项目名称使用系统衬线字体；正文、标签和按钮使用系统无衬线字体。
- 返回、刷新、签署按钮保持至少 `44px` 触控区域，动效在减少动态效果模式下关闭。

## 内容与交互边界

- 保留返回、`CCAT CONTRACTS`、`项目合同`、换一批、批次状态和五份合同列表。
- 每份合同继续展示合同编号、项目名称、委托方、承接方、合同总额、交付期限、难度等级、项目内容、甲乙双方签章区和签署按钮。
- 不修改项目 API、项目状态、本地存储、签署计时或钱包报酬逻辑。
- 保留加载骨架、首次加载错误、刷新错误、已签署红章、其他合同降级和刷新锁定状态。
- 不修改办公室、员工管理、项目倒计时、设置及其他 APP 页面。

## 响应式与验收

- 在 `375×812` 与 `390×844` 视口中保持单列滚动、文字可读、按钮不被遮挡。
- 正常态、加载态、错误态和已签署态均使用同一套白色轻奢设计语言。
- 项目管理测试、完整测试、生产构建和 GitHub Pages 同步均通过后才发布。
