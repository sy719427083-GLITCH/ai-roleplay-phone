# 项目倒计时悬浮按钮与背景可见度设计

## 目标

在不改变项目倒计时、合同数据、领取报酬和页面导航逻辑的前提下，替换底部红色长边框按钮，并让现有花草背景在页面底部和卡片后方清楚可见。

## 已确认设计

- 运行中的底部操作改为珊瑚红实心圆形悬浮按钮。
- 按钮仅显示白色合同图标，不显示文字。
- 按钮尺寸不小于 52 x 52 CSS 像素，保留 `打开完整合同` 的无障碍名称。
- 移除运行状态下的红色长边框和不透明白色底栏。
- 按钮使用轻阴影与背景分离，按下和键盘聚焦状态继续可见。
- 已完成项目仍保留原有“点击领取报酬”主操作，不改领取行为。

## 背景处理

- 继续使用现有 `project-countdown-background.png`，不更换视觉主题。
- 底部操作区域改为透明，使花草不再被整块底栏遮挡。
- 倒计时卡与合同卡降低少量白色不透明度，让背景隐约透出。
- 通过现有背景素材的显示参数提高花草存在感，不使用 CSS 绘制或替代素材。
- 文字区域必须维持可读对比度；背景不得穿透到影响正文识别的程度。

## 范围外

- 不修改项目 API、合同字段、倒计时计算、钱包入账或领取报酬逻辑。
- 不修改合同正文、彩色图标、排版层级和页面导航。
- 不部署线上，也不提升版本号。

## 验收

- 390 x 844 手机视口中，底部显示一个珊瑚红圆形悬浮按钮，且没有红色长框。
- 页面顶部藤叶和底部花草均清楚可见。
- 合同文字保持清晰，卡片边界仍可辨认。
- 运行状态按钮可点击且尺寸达标；完成状态领取按钮保持原样。
- 浏览器无错误或警告；相关测试和生产构建通过。
