# Work APP 项目任务活动设计

## 目标

让办公室人物只在存在进行中的已接项目时显示工作类活动，并用与项目内容相关的具体任务取代笼统的“工作中”。同时将“打印中”从最多接近 15 分钟的场景周期中解耦，缩短为 15–30 秒。

## 已确认规则

### 项目状态门控

- 只有项目倒计时状态为“项目进行中”时，才允许出现工作类活动。
- 工作类活动包括十个具体项目任务以及“打印中”。
- 没有已接项目、项目已完成或项目数据损坏时，不允许出现具体项目任务、旧“工作中”、“做报表”或“打印中”。
- 无进行中项目时，人物仍可聊天、休息、打游戏、刷抖音、摸鱼或下班。人物需要留在自己工位时使用中性状态“待命中”。
- 项目完成后无需等待领取报酬，工作类活动立即停止。

### 十个具体任务

1. 做 PPT
2. 做表格
3. 写项目方案
4. 整理项目资料
5. 收集项目数据
6. 分析项目数据
7. 制作项目报表
8. 核对项目预算
9. 编写交付文档
10. 检查项目成果

具体任务都在人物自己的工位执行，人物下方直接显示对应短标签，不再显示笼统的“工作中”。

### 项目相关性与人物差异

- 任务分配读取当前项目的名称、描述、合同范围、交付物和验收标准。
- 系统在本地对项目内容进行轻量关键词匹配，为十个任务设置偏好。例如设计策划类项目偏向做 PPT 和写项目方案，数据类项目偏向做表格、收集或分析数据、制作项目报表，交付阶段偏向编写交付文档和检查项目成果。
- 分配以项目 ID、人物 ID 和当前时间段为稳定种子，同一时间段内不会反复变更，不同人物尽量不同时执行相同任务。
- 人物原有的专注、纪律、娱乐和社交倾向继续影响工作与非工作活动的选择。存在项目不代表所有人物必须一直工作。
- 此过程完全本地完成，不新增 API 请求。

### 打印生命周期

- “打印中”仅在存在进行中的项目时可被选择。
- 打印持续时间为 15–30 秒，并使用独立的短时结束机制，不再等待 15 分钟场景计划切换。
- 打印结束后，人物离开打印区并重新进入当前活动调度，可能返回工位继续具体项目任务，也可能执行符合时间与人物设定的其他活动。
- 打印区继续保持单人使用与等待规则。

## 数据流与归一化

Work APP 将当前活动项目的完整合同对象传入办公室调度，不再只传项目名称。统一的项目工作状态归一化逻辑在以下入口执行：

1. 本地计划创建后；
2. AI 场景计划解析后；
3. 当前时间段的持久化计划恢复后；
4. 聊天结束后；
5. “我”手动控制结束后；
6. 打印短时活动结束后。

归一化规则如下：

- 无进行中项目时，将所有工作类活动转换为“待命中”并返回人物自己的工位；打印排队状态也一并清理。
- 有进行中项目时，将通用 `working` 或旧标签“工作中”映射为十个具体任务之一。
- 旧 `reporting` 活动保留工位语义，但显示为“制作项目报表”或由项目内容匹配出的另一项具体任务。
- AI 模式仍可决定活动类型，但不能绕过项目门控；无项目时 AI 返回的工作或打印活动必须被本地规则修正。
- 聊天孤儿状态继续沿用至少两人规则，但其回退活动由项目状态决定：有项目时回到具体任务，无项目时回到“待命中”。

## 状态与缓存兼容

- 当前 15 分钟时间段仍用于稳定重建整体办公室场景。
- 打印到期事件拥有独立的毫秒级计时器，触发后生成并持久化新的安全计划，避免关闭再打开 APP 后恢复已过期的打印状态。
- 恢复缓存时若打印的 `endsAt` 已过期，立即重新调度，不先渲染“打印中”。
- 项目从进行中变为已完成时，下一次秒级项目计时更新立即清除工作类活动，不等待办公室时间段变化。

## 错误处理

- 当前项目对象为空、找不到对应项目、项目时间无效或合同字段不完整时，一律按无进行中项目处理。
- 关键词没有命中时使用十项任务的通用权重，仍保证显示具体任务而不是“工作中”。
- AI 返回非法活动、非法目的地或不符合项目门控的工作状态时，使用本地归一化结果；不增加额外 API 重试。

## 测试与验收

### 自动测试

- 进行中的项目能生成十项任务中的具体标签，且不出现“工作中”。
- 项目名称、描述、合同范围、交付物和验收标准都会参与任务偏好判断。
- 同一项目、人物和时间段的任务稳定，不同人物能获得多样任务。
- 无项目、项目已完成和损坏项目数据均不生成具体任务、报表或打印活动。
- 旧缓存与 AI 计划中的“工作中”、“做报表”和“打印中”会按项目状态归一化。
- 打印持续时间始终处于 15–30 秒，并在到期后重新调度及持久化。
- 聊天结束和手动控制结束后恢复到具体任务或“待命中”，不恢复笼统的“工作中”。
- 原有至少两人聊天、工位活动位置、单打印机和 10 秒手动控制规则继续通过。

### 浏览器验收

- 在 375×812 与 390×844 两种视口中验证有项目和无项目场景。
- 有项目时人物下方显示具体任务；无项目时不出现任何工作类标签。
- 使用加速时钟验证打印进入、15–30 秒到期、离开打印区和新状态持久化。
- 验证刷新或重新打开 Work APP 后不会恢复过期打印或旧“工作中”。

## 范围边界

- 不修改办公室视觉、家具、人物尺寸、路线、聊天气泡或底部导航。
- 不新增 API 请求，不改变项目合同、倒计时和领取报酬流程。
- 不引入员工岗位系统；任务相关性仅根据项目合同内容和既有人物倾向决定。
