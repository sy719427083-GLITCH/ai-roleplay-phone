# Work APP 茶水间移除与打印区微调设计

## 目标

从 Work APP 中彻底移除右侧箭头进入的茶水间 / 员工餐厅功能，使工作场景始终停留在办公室。保留办公室内的智能打印资料区，并将其轻微下移、适当缩小，人物点击后的停靠位置同步调整。

## 范围

### 删除

- 办公室右侧的茶水间入口按钮。
- 茶水间场景组件、设施声明、几何数据、避障寻路与对应测试。
- `WorkAppScreen` 中的 `office` / `breakroom` 场景切换状态、茶水间引用和切换处理。
- 茶水间专用样式。
- 茶水间背景、饮品吧台、咖啡机、冰箱、微波炉、零食柜和员工餐桌共 7 张源图片及 `docs` 发布副本。

### 保留

- 办公室场景、办公桌、人物移动和项目功能。
- 智能打印资料区及 `orbit-print-station.png`。
- 打印区点击交互和“正在处理文件”提示。
- 已有茶水间设计与实施文档，作为历史记录保留，不进入运行包。

## 打印区调整

- 视觉定位从 `top: 9%` 调整为 `top: 11%`。
- 尺寸从 `width: 54%; height: 16%` 调整为 `width: 48%; height: 14%`。
- 继续贴近办公室右边缘，保持 `right: 0`。
- 打印区交互停靠点从 `{ x: 93, y: 29 }` 调整为 `{ x: 93, y: 31 }`，使人物站位与图片同步下移。
- 打印区碰撞与路线几何同步使用新布局，避免人物穿过图片。

## 代码结构

- `OfficeScene` 恢复为只接收办公室人物、移动和物件点击所需参数，不再接收茶水间回调。
- `WorkAppScreen` 只渲染 `OfficeScene`，并只使用办公室场景引用与办公室寻路。
- 删除不再有消费者的茶水间模块，避免保留不可达代码。
- 办公室资源模块继续单独声明打印区，确保其不会随茶水间资源被误删。

## 测试与验收

- 先把现有工作界面测试改成“没有茶水间入口、导入、场景切换或样式”的回归断言，并观察测试在旧实现上失败。
- 更新打印区布局与几何测试，先观察旧定位和尺寸导致测试失败，再修改实现。
- 删除茶水间专用测试和模块后，运行全部工作模块测试与项目测试。
- 构建生产包，确认构建产物不包含茶水间文字、代码引用或专用资源。
- 使用引用搜索确认运行代码、`public` 和 `docs` 中没有茶水间遗留；历史设计文档中的文字不计为运行遗留。

## 非目标

- 不修改办公室背景、桌子、人物样式或打印区图片本身。
- 不增加新的房间入口或替代场景。
- 本次不自动部署线上，除非用户另行要求。
