# Work APP 公司创建全屏动画设计

## 目标

重做首次创建公司流程中的两段动画：工作 APP 启动动画与创建完成后的进入公司动画。两段动画必须占满整个手机屏幕，并与现有办公室底图 `public/work-office-assets/orbit-office-background.png` 保持同一种柔和 3D 场景渲染画风。

本次不改创建公司表单、不改公司名称持久化逻辑、不改项目合同或办公室功能。

## 已确认方向

采用 A「连续镜头推进」。视觉世界沿用现有办公室底图：

- 明亮白色圆弧建筑与干净高光地面；
- 鲜明蓝天、柔软云层与轻微梦幻光晕；
- 淡粉、奶黄、白色球形吊灯；
- 绿植与浅紫色墙面作为点缀；
- 柔和 3D 动漫环境渲染，不使用照片写实、抽象渐变、黑金或赛博朋克风格。

## 动画一：打开工作 APP

### 画面

使用独立的竖屏全屏背景图，场景是通往云端公司入口的白色天空步道。入口、圆弧建筑、植物、灯球和天空均属于现有办公室世界。

### 动作

1. 画面从略微放大的天空与步道开始，透明度快速建立。
2. 云层缓慢横移，背景以轻微景深差产生空间感。
3. 镜头沿步道持续向入口推进。
4. `CCAT WORK` 与“工作中心”使用克制的白色文字在下方淡入，再随镜头推进淡出。
5. 约 2.2 秒后切换到现有创建公司页面。

整个动画不出现居中的图标卡片、浮动面板或缩小的场景框。

## 动画二：进入公司

### 画面

使用第二张独立竖屏全屏背景图，场景位于同一建筑入口内部。前景为打开中的白色圆弧门板，门后能看到与办公室底图一致的蓝天窗、淡紫墙、球形吊灯和植物。

### 动作

1. 创建成功后立即用全屏入口画面覆盖创建页。
2. 左右圆弧门板向屏幕两侧打开。
3. 已创建的公司全称在画面下方安全区内淡入，保持可读但不遮挡入口。
4. 镜头穿过门口向室内推进，公司名称随推进淡出。
5. 画面末段与现有办公室底图做短暂叠化，再进入可交互办公室。
6. 总时长约 2.4 秒。

## 全屏与适配

- 动画容器使用固定定位覆盖整个 viewport，并同时支持 `100vh` 与 `100dvh`。
- 背景图以 `cover` 填满屏幕，主体入口保持在中心安全区域。
- 重点检查 390 × 844 手机尺寸，同时保证窄屏不会裁掉入口和公司名称。
- 两段动画右上角保留最小 44px 点击区域的半透明“跳过动画”。
- 创建公司页面仍保留原有返回按钮和输入逻辑。

## 素材

正式实现生成两张独立的竖屏 PNG：

- `work-company-launch-background.png`
- `work-company-enter-background.png`

生成时必须把 `orbit-office-background.png` 作为画风与世界参考。素材写入 `public/work-office-assets/`，发布时由现有 Pages 同步流程复制到 `docs/work-office-assets/`。

## 组件与状态

- `WorkCompanyOnboarding` 继续维护 `launch → create → enter` 三阶段状态机。
- 公司数据仍在点击创建时立即持久化，进入动画结束或跳过后调用 `onComplete`。
- 关闭创建页后再次打开仍播放启动动画；公司已保存后以后直接进入办公室。
- 动画素材加载失败时显示同画风的白蓝渐变兜底背景，流程仍按时继续，不阻塞创建或进入办公室。

## 动效与无障碍

- 默认使用 CSS transform、opacity 和门板动画，不引入视频依赖。
- `prefers-reduced-motion: reduce` 下不执行长距离推进与云层移动，只保留 150ms 淡入淡出。
- 跳过按钮始终可见并可键盘操作。
- 动画区域保留“工作 APP 启动”和“正在进入公司”的语义标签。

## 验证标准

- 两段动画均实际铺满屏幕，没有居中卡片或四周露底。
- 画风、色彩、建筑语言与 `orbit-office-background.png` 一致。
- 顺序保持“启动动画 → 创建公司 → 进入动画 → 办公室”。
- 公司名称最多五个字，固定后缀“有限公司”，持久化行为不变。
- 创建完成后再次打开以及刷新后再次打开都直接进入办公室。
- 跳过动画、减少动态效果和素材加载失败不会阻塞流程。
- 相关单元测试、全量测试、生产构建和 390 × 844 浏览器实测均通过。
