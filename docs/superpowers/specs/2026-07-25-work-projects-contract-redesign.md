# Work APP 项目合同正式纸质版设计

## 范围

将项目管理预览页从编辑任务板改为“正式纸质合同”界面。保留五个项目、650ms 刷新骨架、签署后锁定列表等现有逻辑；本轮仍使用示例数据，不接真实 API、不发布线上版本。

## 页面结构

1. 顶部左侧返回，中间标题“项目合同”，右侧为带图标的“换一批”按钮。
2. 状态区显示“待签署合同 5 份”；任意合同签署后改为“合同已生效，本批合同已锁定”。
3. 页面纵向展示五份合同缩略页，每份包含：
   - 合同编号；
   - 项目名称；
   - 委托方“CCAT 工作中心”；
   - 承接方“待签署”；
   - 合同总额；
   - 交付期限；
   - 项目内容；
   - 难度等级；
   - 甲方与乙方签名线；
   - “签署合同并开始”按钮。

## 视觉规则

- 页面使用暖灰桌面背景，合同使用米白纸张表面。
- 每份合同采用外实线加内细线的双层边框，圆角控制在 2–4px。
- 标题使用宋体或 Georgia 衬线字体；编号和辅助字段使用等宽系统字体。
- 主文字为墨黑，辅助文字为印刷灰；主操作为深蓝黑，不使用渐变。
- 金额采用正式文案“合同总额：人民币 ¥1,500”，不使用绿色大号数字。
- 签署状态使用倾斜的红色“已签署”印章，并同时提供文字状态，不能只依赖颜色。
- 不加载外部字体或新增依赖，所有按钮触控区域至少 44px。

## 交互状态

- 正常状态：五份合同均可签署，“换一批”可用。
- 刷新状态：显示五份带双线轮廓的合同骨架，保持页面高度稳定。
- 已签署状态：选中合同出现“已签署”红章和生效日期，按钮显示“合同执行中”；另外四份合同降低强调并禁用。
- 锁定状态：右上角按钮显示“已锁定”并禁用，不能生成新合同。
- 减少动态效果模式下取消旋转和骨架动画，状态仍可通过文案识别。

## 数据与文案边界

- 不修改 `projectPreviewModel.js` 的数据结构和函数签名。
- 委托方与承接方为本地预览展示文案，不写入项目数据。
- 合同编号由项目索引与当前 revision 生成稳定展示值，例如 `CCAT-2026-001`。
- 签署日期使用预览固定文案“今日生效”，避免自动化截图随日期变化。

## 验收

- 375×812 与 390×844 下合同字段、签名线、签署按钮和滚动均正常。
- 正常状态截图能看到“签署合同并开始”；锁定状态能看到红色“已签署”印章。
- 刷新后仍为五份合同，签署后换一批和全部签署按钮禁用。
- 项目页、生产构建和办公室浏览器回归全部通过。
- 不修改办公室、员工管理、工作倒计时和设置页。
