# Work APP 打印区右端下压设计

## 目标

保留打印区当前的尺寸和位置，以左侧底边为固定支点，使右端向下倾斜，与办公室背景右侧绿植花盆底部形成自然的同高关系。用户在视觉对比中选择 B 方案，旋转角度为顺时针 `2deg`。

## 视觉规则

- 打印区继续使用 `top: 11%`、`right: 0`、`width: 48%`、`height: 14%`。
- 使用 `transform-origin: left bottom` 固定左侧底边。
- 使用 `transform: rotate(2deg)` 让右端向下，左端锚点不移动。
- 点击按压时使用 `rotate(2deg) scale(.975)`，避免通用按压样式覆盖旋转角度。
- 不修改打印区 PNG、背景图、办公桌、人物或其他设施。

## 路径与碰撞

- 在 `OFFICE_LAYOUT.printStation` 中声明 `rotation: 2`，使视觉和几何共享同一个角度值。
- 打印区可见矩形仍从 PNG 的 alpha 边界推导。
- 以打印区容器左下角为旋转支点，对可见矩形四个角应用与 CSS 相同的顺时针二维旋转。
- 使用旋转后四个点的最小和最大坐标生成保守的轴对齐碰撞矩形，再应用现有头像安全间距。
- 交互停靠点继续为 `{ x: 93, y: 31 }`；若回归测试证明它落入旋转后可见区域，则只向下微调 y，不改变 x。

## 组件边界

- `office.css` 负责视觉旋转、支点和按压状态。
- `officeGeometry.js` 负责共享角度声明和旋转后的碰撞边界。
- `OfficeScene`、`officeAssets.js` 与图片资源无需改动。

## 测试与验收

- 先更新样式测试，要求 `transform-origin: left bottom`、`rotate(2deg)` 与按压状态保留旋转，并观察旧样式失败。
- 先更新几何测试，要求 `OFFICE_LAYOUT.printStation.rotation === 2`，并观察旧几何失败。
- 新增旋转边界断言：右侧可见底边比未旋转状态更低，左侧底部锚点保持不变，交互点不落入打印区可见区域。
- 运行办公室寻路测试，确认所有目的地仍可到达且路线不穿过旋转后的打印区。
- 在 `390 × 844` 手机尺寸下视觉检查：打印区左侧不移动、右端下压、右端底部与绿植花盆底部视觉同高、控制台无错误。

## 非目标

- 不改变打印区大小、整体 top/right 定位或人物停靠点的横向位置。
- 不重新生成或编辑打印区 PNG。
- 不调整绿植或办公室背景。
- 本次不自动部署，除非用户另行要求。
